# Ritfimi

Ritfimi er íslenskt ritunar- og fingrafimiforrit fyrir nemendur. Aðeins réttur
næsti stafur er samþykktur. Ef nemandi ýtir á rangan takka blikkar rétti takkinn
á íslenska skjályklaborðinu.

## Opna forritið

[Opna Ritfimi](https://ingimar90.github.io/ritfimi/)

## Setja upp sem app

- **Windows / Chromebook / Android:** Opna vefslóðina og velja **Setja upp app**.
- **iPhone / iPad:** Opna í Safari, ýta á deilingartáknið og velja **Bæta við heimaskjá**.
- Forritið virkar án nettengingar eftir fyrstu opnun.

## Innihald

- 10 erfiðleikastig.
- Nákvæmlega 500 verkefni.
- Orð, orðasambönd, setningar, greinarmerki, samtöl og stuttir textar.
- Shift+2 setur sjálfkrafa inn réttar íslenskar gæsalappir: „ og “.
- Broddstafir virka með ChromeOS/Chromebook composition-atburðum.
- Ritunarreiturinn stækkar með löngum texta, brýtur hann niður á línur og fylgir bendlinum.
- Framvinda vistast á tækinu.
- Hljóð má kveikja og slökkva.

## Keyra staðbundið

Þar sem service worker krefst vefþjóns er best að keyra:

```bash
python -m http.server 8000
```

Opna síðan `http://localhost:8000`.
